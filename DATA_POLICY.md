# Public Data Policy

## Allowed in this repository

- Deterministically generated synthetic reviews
- Synthetic schema and edge-case fixtures
- Global or sufficiently coarse anonymous aggregate metrics
- Reproducible evaluation code, tests, and documentation
- Download instructions that point to the original hosting pages

## Not allowed in this repository

- `Reviews.csv`, `database.sqlite`, `finefoods.txt.gz`, or other source copies
- Real review text, summaries, or row-level excerpts
- User IDs, profile names, product IDs, or linkable behavioral records
- User-level, product-level, or small-cell reports
- Models, vectorizers, vocabularies, embeddings, or caches fitted on the source
  data
- Course materials, reference solutions, screenshots, logs, or notebooks that
  expose third-party rows
- Secrets, credentials, local machine paths, or downloaded archives

Pseudonymization alone is not sufficient: stable hashed identifiers and free
text can remain linkable or reveal personal information.

Public benchmark tables must be generated by reproducible code and contain
only aggregate results. If a metric, artifact, or example could reveal or help
reconstruct a source record, it remains private.

When ownership or redistribution rights are uncertain, link to the original
source instead of mirroring the data.
